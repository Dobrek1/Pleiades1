# Pleiades1 / Плеяды

Полёт: эллипс, тяга, варп. Баржа пока расходник.

**Unity:** `6000.6.0f1`. Открой корень репо в Hub → Play. `PleiadesBoot` поднимает сцену сам.

## Почему «не летело»

На 1× виток LEO ≈ 90 минут. Корабль стоит. Гоман — не руль, а разовая кнопка. Камера не ехала за кораблём. Орбита была только круговая.

Сейчас: старт **варп ×3600**, **W/S** жгут, камера **F** за баржей, жёлтая линия — твоя орбита.

## Управление

| Клавиша | Действие |
|---|---|
| W / S | проград / ретро |
| Q / E | радиал внутрь / наружу |
| Shift | форсаж |
| 1 2 3 4 | варп ×1 / ×60 / ×3600 / ×сутки |
| Пробел | пауза |
| F | камера за кораблём |
| C | циркуляризация здесь |
| G / L | Гоман к ГСО / Луне с **текущего** r |
| колёсико / ПКМ | зум / панорама (ПКМ снимает follow) |

Пока жмёшь тягу, варп не выше ×60.
