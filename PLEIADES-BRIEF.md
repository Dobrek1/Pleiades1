## 1. Что это за игра

Реалистичный космосим **вид сверху**. Не Kerbal-песочница «для галочки» и не аркадный X4.

Ощущение:

- ремейк духа **Космических рейнджеров**
- вайбы **Skyrim** (мир не крутится вокруг игрока)
- **RimWorld** (герои-пешки, не империя микроменеджмента тысяч юнитов)
- **Kenshi** (мир равнодушен, присутствие тела)
- **Mount & Blade 2 Bannerlord** (встречи на прогруженной карте, решение на месте)
- **Terra Invicta** (астромеханика, окна, колодцы)
- **X4** как потолок масштаба (флоты, станции, государства) — **не стартовый скоуп**

Игрок может быть капитаном ржавой шахтёрской баржи **или** (позже) строить флотилии, станции, государства. Старт — баржа.

Кастомизация максимальная **в долгую**. В ранних билдах — модульная масса, не конструктор мечты.

## 2. Законы (нарушил — чини, не спорь)

### Реализм vs темп

Это будущее: двигатели сильнее нынешних, гравиманёвры считаются. Земля→Марс — **месяц–два**, не годы и не 3 минуты. Есть **промотка времени**. Важное событие **ставит паузу**. Без паузы промотки нет.

### Пешки не масштабируются на империю

Ограниченное число героев. Остальные — NPC. Понравился NPC — игрок может сделать его пешкой (как Norland).

Число героев выбирает игрок:

- капитан-одиночка, люди как расход
- капитан с «гаремом» 9 любовниц на ключевых постах — **если так хочет игрок**, это валидный отыгрыш, не мораль агента
- трое мужиков, мужское приключение
- что угодно в разумном лимите героев

Не делай RimWorld на 80 колонистов космопорта.

### Физика vs кастомизация

Ранние билды: **модульная система масс**, не полный ship builder. Каждый модуль и груз меняют мокрую массу → Δv. Лёд в трюме не бесплатный.

### Астромеханика обязательна

Считать, не рисовать «кружочки вокруг планеты»:

- Δv, vis-viva, ракетное уравнение
- окна запуска
- гравитационные колодцы / SOI (patched conics — следующий слой после Земля+Луна)
- Гоман, эксцентриситет, истинная аномалия
- эффект Оберта — учитывать в дизайне, не обязательно в первом спринте

PhysX **не считает орбиты**. Орбиты считает `Pleiades.CoreSim` (чистый C#, без `UnityEngine`).

### Встречи

Как Bannerlord: персонажи встречаются на **прогруженной карте**, говорят, решение принимается **на карте**, не в отдельном vis-novel экране на 40 узлов.

### Иммерсия

Не Space Haven: не пластик, не картон, не «игрушечная» карта. Масштаб должен читаться: LEO — Земля занимает кадр, Луна — край колодца, гелиоцентр — орбиты планет.

### Слои

Не класть пешек, государства, диалоги, квесты, пока не стоит:

1. Play без ошибок
2. Земля-колодец + баржа + Гоман + промотка + пауза на прибытии
3. Карта не картон (масштаб, Луна, камера)
4. Одна встреча на карте

Пешки — после этого.

## 3. Архитектура кода

```
Assets/Pleiades.CoreSim/     чистая симуляция, NO UnityEngine
  AstroMath.cs               G, μ, vis-viva, ракетное уравнение, SOI
  GravityBody.cs             Солнце / Земля / Луна, массы, радиусы
  Kepler.cs                  распространение, круговая орбита, burn prograde
  Hohmann.cs                 план перехода (Δv ухода, Δv прибытия, TOF)
  SimShip.cs                 модули, масса, топливо, TryBurn
  SimWorld.cs                время, warp, пауза, interrupt, Destinations
  Pleiades.CoreSim.asmdef    "noEngineReferences": true

Assets/Pleiades/             только вид
  PleiadesBoot.cs            один компонент: Play сам собирает сцену
  MapView.cs                 Земля, Луна, орбиты, камера сверху
  WatchHud.cs                вахта (OnGUI)
  Pleiades.asmdef            references: Pleiades.CoreSim
```

Масштаб вида: `1 Unity unit = 1000 км` (`AstroMath.MetersPerUnit = 1e6`).

Плоскость эклиптики: XZ, камера сверху (Y).

## 4. Игровой вертикальный срез (уже спроектирован)

Стартовая баржа «Ржавая баржа»:

- Isp 900 с (ЯТР, будущее)
- топливо ~18 т
- модули: рама, каюты×4, трюм, двигатель, бак LH2, радиатор
- старт: LEO 200 км

Цели первого среза:

| id | имя | суть |
|---|---|---|
| geo | ГСО | ~3.94 км/с от LEO, TOF часы |
| lunar | Луна | 384 400 км, край колодца |

Поведение:

- Пробел — пауза
- 1 / 2 / 3 / 4 — 1× / 60× / 1 ч/с / 1 сут/с
- колесо — зум, ПКМ — пан
- кнопка ухода считает Гоман от текущего радиуса
- не хватает Δv — interrupt Fuel, пауза
- прибытие — циркуляризация, interrupt Arrival, пауза, warp сбрасывается в 1
- слайдер груза меняет PayloadKg → AvailableDeltaV

Контрольные числа (не ломай):

- круговая скорость / vis-viva / Гоман LEO→ГСО: уход + прибытие суммарно порядка **3.9 км/с**
- если груз съел запас — до ГСО не летим. Это фича, не баг.

## 7. Спринты. Делай только текущий, если не сказали иначе

**Спринт 1 — Play живой**

- проект открывается в 6000.6.0f1 без красного Console
- Boot создаёт Землю, Луну, баржу, вахту
- Гоман LEO→ГСО и LEO→Луна
- промотка + пауза на прибытии и на «нет топлива»
- груз жрёт Δv

**Спринт 2 — карта не картон**

- масштаб читается (LEO / цислунарье / система)
- Земля не серый шарик-игрушка: хотя бы terminator / атмосфера / нормальный материал
- Луна на 384 400 км, орбита в кадре при отъезде
- корабль не теряется в пикселях (мин. размер маркера)

**Спринт 3 — одна встреча на карте**

- Bannerlord: два маркера, сблизились, разговор на карте, 2–3 решения, последствия (топливо / груз / пешка-флаг)
- без квестового комбайна

**Потом, не сейчас:** пешки-герои, интерьер, станции, флоты, фракции, государства, полный ship builder.
